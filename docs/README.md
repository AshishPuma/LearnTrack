# LearnTrack – Student & Course Management System

## Project Description

LearnTrack is a console-based application built using Core Java.
It allows administrators to manage:

* Students
* Courses
* Enrollments

The project demonstrates key Java concepts such as:

* Object-Oriented Programming (OOP)
* Encapsulation, Inheritance, Polymorphism
* Collections (ArrayList)
* Layered architecture (Entity → Repository → Service → UI)
* Basic exception handling

---

## How to Compile and Run

### Using Terminal

1. Navigate to the project root directory:

```
cd LearnTrack
```

2. Compile all Java files:

```
javac -d out src/com/airtribe/learntrack/**/*.java
```

3. Run the application:

```
java -cp out com.airtribe.learntrack.Main
```

---

### Using IntelliJ / IDE

1. Open the project in IntelliJ IDEA
2. Mark `src/` as **Sources Root**
3. Open `Main.java`
4. Click Run

---

## Features

* Add, view, update, and deactivate students
* Add and manage courses
* Enroll students into courses
* View enrollments by student

---

## Technologies Used

* Java (Core Java)
* ArrayList (Collections)
* Console-based UI (Java Based on System.in and System.out)
