# LearnTrack
Student & Course Management System

LearnTrack is a small, console-based Java application to practice core Java concepts: classes, objects, inheritance, collections, and basic exception handling.

Quick start (from project root in PowerShell)

Compile:

```
javac -d out -sourcepath src src/com/airtribe/learntrack/Main.java
```

Run:

```
java -cp out com.airtribe.learntrack.Main
```

See `docs/Setup_Instructions.md` for environment setup instructions and `docs/JVM_Basics.md` for a short explanation of JVM/JRE/JDK.
